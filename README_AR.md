# RaveRayane — تعديل ريف على الايفون (بدون ماك)

## الملفات
- `Tweak.m` الكود كامله
- `Makefile` إعدادات البناء
- `.github/workflows/build.yml` يبني الـ dylib على GitHub مجانًا

## الخطوات (كلها من الجوال)
1. سوّ حساب على github.com (مجاني) وسوّ Repository جديد، سمّه RaveRayane.
2. ارفع `Tweak.m` و `Makefile` (Add file ← Upload files).
3. الملف المخفي: Add file ← Create new file، واكتب في خانة الاسم بالضبط:
   `.github/workflows/build.yml`
   والصق محتوى ملف build.yml.
4. روح تبويب Actions، شغّل "Build RaveRayane" (Run workflow) وانتظر دقيقتين-خمس.
5. افتح التشغيلة الناجحة ونزّل `RaveRayane-dylib` (zip) من Artifacts، وفك الضغط من تطبيق الملفات.
   - لو فشل البناء: انسخ لي نص الخطأ وأصلحه لك.
6. حقن الملف: في تطبيق يدعم الحقن (Feather أو ESign) أضف Rave-2857.ipa،
   اختر "Inject / Tweaks" وحدد `RaveRayane.dylib`، ثم وقّع وثبّت.
   (بخصوص "n8n plus": تأكد إن عنده خيار حقن dylib، لو لا استخدم Feather/ESign.)

## أول تجربة
- ادخل غرفة: لازم يظهر زر عائم دائري (تقدر تسحبه).
- ما ظهر الزر؟ غالبًا اسم شاشة الغرفة غير صحيح. أرسل لي الخطأ أو القائمة، والحل: نغيّر "اسم شاشة الغرفة" من الإعدادات ← متقدم بدون إعادة بناء (تحتاج تفتح اللوحة؛ فعّل "الفتح التلقائي" أو أعطني نسخة معدلة من الكود).
- الشعار ما تبدّل؟ "نسخ أسماء الصور بالشاشة" من الصفحة الرئيسية، وأرسلها لي، ونحط الكلمة في "كلمات الشعار".
- الرسائل السريعة: أول تجربة قد تحتاج تعديل (نحتاج نعرف زر الإرسال).

## اللي مو موجود (حسب طلبك)
دمج الأصوات بالمايك، إعدادات جودة المايك، تبويب الوسائط. والأصوات تشتغل على جوالك بس.
